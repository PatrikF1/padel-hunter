Izvori

Oglasnici se provjeravaju svakih 90 s, trgovine svakih 15 min. Bez praga javlja samo apsurdne cijene (≥ 30 % ispod uobičajene). Radi dok je server (ili računalo) upaljen.

Mobitel

  1. Mobitel mora biti na istoj Wi-Fi mreži kao ovo računalo.
  2. Skeniraj QR kod kamerom mobitela. Mobitel zapamti ključ, pa sljedeći put samo otvori adresu.
  3. U pregledniku mobitela odaberi Dodaj na početni zaslon i dobit ćeš ikonu kao aplikacija.
  4. Ako se ne otvara, Windows je možda blokirao pristup: dopusti Pythonu "Privatne mreže" u vatrozidu (prozor se pojavi pri prvom pokretanju).

Izvan kuće: najjednostavnije je instalirati Tailscale na računalo i mobitel (besplatno), pa ista adresa radi s bilo kojeg mjesta.

Telegram obavijesti

  1. U Telegramu otvori @BotFather, pošalji /newbot i prati upute.
  2. BotFather ti da token, zalijepi ga ovdje i spremi. Token ostaje samo na tvom računalu.
  3. Otvori svog novog bota i pošalji mu /start.
  4. Klikni Poveži, pa Pošalji test.

eBay API preporučeno, bez njega eBay povremeno blokira pretragu

  1. Prijavi se na developer.ebay.com (besplatno) → Application Keys → Production → Create a keyset.
  2. Kopiraj App ID (Client ID) i Cert ID (Client Secret) ovdje.
