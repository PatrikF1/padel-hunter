🎾 Padel Hunter

Oglasnici se provjeravaju svakih 90 s, trgovine svakih 15 min. Bez praga javlja samo apsurdne cijene (≥ 30 % ispod uobičajene). App mora biti pokrenut.

Telegram obavijesti

  1. U Telegramu otvori @BotFather, pošalji /newbot i prati upute.
  2. BotFather ti da token, zalijepi ga ovdje i spremi. Token ostaje samo na tvom računalu.
  3. Otvori svog novog bota i pošalji mu /start.
  4. Klikni Poveži, pa Pošalji test.

eBay API (preporučeno - bez njega eBay povremeno blokira pretragu)

  1. Prijavi se na developer.ebay.com (besplatno) → Application Keys → Production → Create a keyset.
  2. Kopiraj App ID (Client ID) i Cert ID (Client Secret) ovdje.
